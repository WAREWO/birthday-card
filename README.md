# Selamat Ulang Tahun, Mamah

Kartu ulang tahun berbentuk scrapbook untuk **Mamah**, dari **Putri**.
Isinya foto-foto keluarga, surat, dan doa buat Mamah.

## Membuka

Klik dua kali **index.html**, lalu scroll ke bawah. Tidak perlu instalasi apa pun.
Seluruh folder ini juga bisa diunggah ke hosting statis seperti GitHub Pages.

## Lagu

Lagu *Andai Aku Besar Nanti* diputar otomatis mulai dari menit **0:51**, dan
mengulang dari 0:51 saat selesai. Kebanyakan browser memblokir suara sebelum
halaman disentuh, jadi kalau lagu belum bunyi, lagu akan mulai begitu halaman
disentuh, diklik, atau ditekan tombol keyboard.

## Isi

1. Sampul untuk Mamah.
2. Surat dari Putri dan beberapa foto bareng.
3. Foto-foto lama dari album keluarga.
4. Foto-foto bareng Mamah.
5. Doa buat Mamah.
6. Penutup, dengan tombol **Peluk Mamah**.

Ketuk foto mana pun untuk melihatnya lebih besar.

## Berkas

- `index.html` — semua tulisan dan foto.
- `style.css` — tampilan untuk laptop dan HP.
- `script.js` — animasi, tampilan foto besar, dan lagu.
- `photos/puki/` — foto-foto keluarga.
- `audio/andai-aku-besar-nanti.mp3` — lagu latar.
- `art/lily-garden.svg` — gambar latar bunga.
